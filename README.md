# 🚀 AlanyGram (Telegram Mod для iOS)

Модификация официального клиента Telegram для iOS с расширенными функциями приватности и медиа.

**Автор:** Aslan  
**VK:** [vk.ru/aslanbostanov](https://vk.ru/aslanbostanov)

---

## ⚡ Возможности

В приложении Telegram появляется отдельный раздел: **«Настройки AlanyGram»** с независимыми тумблерами:

1. 👁️ **Невидимка в чатах (Ghost Mode):**
   - Вы можете читать любые сообщения, а у собеседника они остаются непрочитанными (одна галочка).
   - Блокируется отправка сетевого запроса `readHistory`.

2. 🎭 **Невидимка в историях (Story Ghost):**
   - Просматривайте любые истории (Stories) полностью анонимно.
   - Вы не появитесь в списке зрителей автора.

3. 🔥 **Обход одноразовых фото, видео и голосовых (Anti View-Once):**
   - Таймер сгорания не запускается.
   - Собеседник **не получает** уведомление о том, что вы открыли медиа.
   - Добавлена возможность **сохранить** фото/видео/голосовое напрямую на устройство.

4. 🗑️ **Анти-удаление сообщений (Anti-Delete):**
   - Если собеседник удаляет сообщение («Удалить у всех»), оно остаётся в вашем чате.

5. ℹ️ **Вкладка «О разработчике»:**
   - Прямой переход на страницу автора: [vk.ru/aslanbostanov](https://vk.ru/aslanbostanov).

## 🛠️ Структура проекта

- `Tweak/AlanyGram.x` — Logos/Objective-C твик, перехватывающий методы Telegram (прочтение, сгорание медиа, удаление).
- `Tweak/AlanyGramSettings.h`, `AlanyGramSettings.m` — Интерфейс настроек и сохранение параметров.
- `Makefile`, `control` — Конфигурация компилятора Theos.
- `.github/workflows/build.yml` — Автоматическая сборка готового `.ipa` файла через GitHub Actions (бесплатно, без необходимости иметь Mac).

## 📲 Как получить готовый `.ipa` (Сборка без Mac через GitHub)

Поскольку для сборки под iOS нужен macOS/Xcode, а вы работаете на Windows, настроен **GitHub Actions** (облачный Mac):

1. Создайте свой репозиторий на [GitHub](https://github.com) (например, `AlanyGram`).
2. Загрузите файлы из этой папки (`AlanyGramipa`) в ваш репозиторий.
3. Откройте вкладку **Actions** в репозитории на GitHub.
4. Выберите воркфлоу **«Build AlanyGram IPA»** и нажмите **«Run workflow»**.
5. Через 3–5 минут перейдите в завершившийся процесс и скачайте готовый архив **`AlanyGram-IPA`** (внутри будет `AlanyGram.ipa`).

## 📱 Как установить `.ipa` на iPhone

- **TrollStore** *(iOS 14.0 — 17.0)*: Самый идеальный вариант — постоянная установка без отзыва сертификатов и без ПК.
- **Sideloadly** *(Windows / Mac)*: Установка через кабель по бесплатному Apple ID.
- **AltStore**: Установка через Wi-Fi / ПК.
- **Scarlet / ESign**: Установка прямо с телефона с помощью корпоративного или персонального сертификата.
